The production board: every issue, flowing Backlog → Ready → In progress → In review → Done.

* Board: the flow, grouped by Status, with the Estimate sum per column.
* By milestone: a table grouped by milestone, for planning.
* Roadmap: Start and Target dates on a timeline.

Estimates are Fibonacci points (1, 2, 3, 5, 8, 13); 13 means split it. Priority runs `prio:p0` (main is broken) to `prio:p3` (someday). Merges and closes move cards to Done automatically; never hand-move a card there. The rules live in the repo's AGENTS.md.
